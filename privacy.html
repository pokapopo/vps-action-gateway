VPS Action Privacy Policy

This is a private, single-user integration. It processes only the requests submitted by the authenticated GPT Action in order to inspect and maintain the owner's VPS.

Request data and command output are not sold, shared for advertising, or used to train a separate model. Operational logs may temporarily contain timestamps, action names, status codes, and redacted diagnostic output for security and reliability.

Credentials, cookies, SSH identities, system password databases, disk partition controls, and kernel boot settings are excluded by the gateway policy. File writes use conflict detection, and destructive operations use recoverable deletion where supported.

Access can be revoked by rotating the private API key or disabling the gateway service.
